# Indian-Stock-Market-Analysis-Dashboard
## About the Project
This interactive Power BI dashboard provides a comprehensive analysis of the Indian stock market. It visualizes market capitalization, stock prices, PE ratios, and financial performance across 5,258 companies.

## Tools & Skills Used
* Power BI
* Data Cleaning & Transformation
* Financial Data Analysis
* Dashboard Design (Dark Navy & Gold Theme)

## Key Metrics Analyzed
* **KPI Cards:** Total Companies, Total Market Cap (₹48M Cr), Average Stock Price, and Average PE Ratio.
* **Bar Chart:** Identified the Top 10 companies by Market Capitalization (Reliance, HDFC Bank, ICICI Bank, etc.).
* **Scatter Chart:** Analyzed the relationship between Return on Capital Employed (ROCE) and PE Ratios.
* **Column Chart:** Evaluated Quarterly Profit Growth versus Sales Growth.
* **Interactive Slicer:** Added a searchable list to filter the dashboard by specific companies.
